# RUNBOOK — firesdk

## 1. Footprint
**No services.** FireSDK is a client library (Python, PHP, JS) with no host, vhost, unit, cron, queue or DB.

| Item | Where |
|---|---|
| Source | `/var/www/firesdk` (test1 only), GitHub `howlettjp-code/FireSDK` |
| PyPI | `fire-sdk` (vault slug `pypi-fire-sdk` registry row) |
| npm | `@moduspromethean/fire-sdk` (registry row `npm-fire-sdk`) |
| Packagist | auto-syncs from tag via `.github/workflows/split-php.yml` |
| Species registry | regenerated by `scripts/generate_species.py` from Fire `GET /v1/capabilities` (manual, checked in) |

Nothing is deployed to prod1; the SDKs call the Fire API (`fire.prosaga.net`, owned by the `fire` project).
